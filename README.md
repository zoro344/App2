# Aether – Android App

**Aether** is a native Android anime streaming app.

## How to build
1. Open the folder `anikentv-release` in **Android Studio**.
2. Let Gradle sync.
3. Click Run or Build APK.

The app will appear on your device as **Aether** with the new logo.

minSdk 26 | targetSdk 36 | Kotlin + Jetpack Compose
